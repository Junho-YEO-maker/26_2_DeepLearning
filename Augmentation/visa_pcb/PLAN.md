# A팀 VisA PCB 이상 데이터 증강 계획

VisA PCB 4종에서 제한된 진짜 불량으로 복사-붙여넣기, cTransGAN, UniPCB 방식, 인페인팅 + LoRA를 비교합니다. B팀은 실제 불량 K장과 생성 데이터를 조합해 정상/불량 분류에서 필요한 최소 실제 불량 수를 평가합니다.

| 단계 | 작업 및 완료 기준 | 상태 |
|---|---|---|
| 1. 데이터와 분할 | pcb1~4 원본 폴더, `image_anno.csv`, 공식 split CSV 및 클래스 ID 마스크를 확인한다. 다중 라벨 층화로 PCB당 불량 33/67, 정상 80/20을 분리한다. seed 7017, 파일·디코딩 픽셀 해시 및 heldout 접근 차단을 검증한다. | 완료 |
| 2. 복사-붙여넣기 | gen_train 불량의 마스크 패치를 정상 gen_train에 무작위 위치·회전으로 배치하고 경계를 블렌딩한다. PCB별 500장, PNG 마스크·CSV·품질·다양성·비용·그림을 생성한다. | 완료 |
| 3. cTransGAN | 저자 코드와 라이선스를 확인한다. VisA 클래스 조건을 학습한 Transformer GAN으로 결함 ROI를 생성한다. PCB별 학습을 재개할 수 있게 하고, 500장씩 생성해 2단계 평가와 비교한다. | Colab T4 본실험 완료 |
| 4. UniPCB 방식 | [논문](https://arxiv.org/abs/2605.04635)과 [코드](https://github.com/House-yuyu/UniPCB)를 검토한다. SD v1.5 + ControlNet에 Otsu Canny와 마스크 기반 클래스·면적·3×3 위치·개수 프롬프트를 넣는다. Depth Anything V2는 GPU 여유가 있을 때 사용한다. T4 축소 설정과 원논문 차이를 기록하고 PCB별 500장과 공통 지표를 검증한다. | 계획, 본실험 미실행 |
| 5. 인페인팅 + LoRA | SD v1.5 인페인팅에 PCB별 LoRA를 학습한다. 정상 이미지·마스크와 4단계 프롬프트를 입력으로 주고 마스크 영역을 채운다. 500장씩 생성하고 마스크 밖 구조 보존을 검사한다. | 계획 |
| 6. 결과 정리 | `results/A_summary.csv`와 PCB별 실제 불량·네 모델 비교 및 결함 확대 그림을 정리한다. KID, 다양성, 비용 및 B팀 해석 범위를 요약한다. | 계획 |

## 공통 평가 및 실행 기준

- 학습, 조건 선택, 품질 참조는 고정 gen_train으로 제한한다. 단계마다 소형 더미 데이터로 학습·생성·재개·평가를 연결하고, 결과를 검증한 후 다음 단계로 진행한다.
- 주 지표 KID는 PCB별 gen_train 불량 33장과 생성 500장을 비교한다. 부분집합 크기 25, 반복 100회의 평균±표준편차를 보고한다. FID는 작은 참조 수의 영향을 명시한다.
- 다양성은 생성 이미지 1,000쌍의 평균 LPIPS로 측정한다. PSNR/SSIM은 대응 원본 정상에 대한 구조 보존 보조값으로 표시한다. 학습 시간, PyTorch GPU 피크 메모리, 이미지당 생성 시간을 기록한다.
- `nvidia-smi` 확인 후 Colab T4 16GB 설정을 기본으로 쓴다. fp16, gradient checkpointing, 배치 크기와 누적 설정은 YAML에서 관리한다. A100은 별도 프로필을 사용한다.
- PCB별 체크포인트와 파일별 메타데이터를 Drive에 남겨 중단 후 재개한다. 출처·라이선스·원논문 변경점은 README에 기록하고 미실행 항목의 이유를 남긴다.

## B팀 K장 실험 연계

현재 `splits/`와 `outputs/{model}/{pcb}/`는 A팀의 33장 모델 비교 프로토콜입니다. 팀 저장소의 `Dataset/visa/splits/train_K{k}_seed{s}.csv`와 `test.csv`를 사용하는 K장 실험에는 K와 seed별 소스 검증과 생성기 재학습 또는 재생성이 필요합니다.

1. B팀과 공통 시험셋을 고정하고, 생성기 학습·조건용 정상과 불량의 경로/해시가 시험셋과 겹치지 않는지 확인한다.
2. K장 실험에서 복사-붙여넣기는 K장의 허용 불량에서만 샘플링한다. 학습형 생성기는 해당 K장으로 초기 가중치에서 학습하고, 해당 K 목록으로 마스크·조건을 제한한다. 33장 결과를 활용할 경우 생성기의 실제 불량 예산 33장을 별도 표기한다.
3. B팀 규약의 `Dataset/generated/{방법}/K{k}_seed{s}/manifest.csv`를 작성한다. `image,mask,label,source_image,score`를 기록하며 `source_image`는 해당 K 목록에서 가져온 불량 원본이다. `meta.csv`의 `source_normal`과 `source_anomaly`를 함께 보존한다.
4. B팀은 동일 시험셋과 시드에서 실제 K장 조건과 실제 K장+생성 조건을 비교한다. 최소 K 판단 기준과 반복별 분산은 B팀 결과에서 명시한다.
